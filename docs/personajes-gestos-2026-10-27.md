# Gestos de los tres amigos

Herramienta: generador de imágenes integrado, habilidad imagegen. Referencia: `public/assets/characters/amigos-comic-unificado-v1.webp`. Resultado original conservado: `public/assets/characters/amigos-expresiones-v1.png`; distribución: `amigos-expresiones-v1.webp`. La hoja se consume sin recortar el original, mediante tres columnas y tres filas de CSS.

Prompt final: «Use case: illustration-story. Asset type: one clean 3 by 3 character expression sprite sheet for an educational app for age six. Reference image: the already approved comic trio, preserve exactly these three illustrated children and their clothing, hair, facial identity, apparent age and warm detailed ink-and-watercolor comic style. Three perfectly equal columns: Adri in navy/orange on LEFT, Juan in light blue in CENTER, Cayetana blonde floral dress on RIGHT. Three perfectly equal rows: TOP row thoughtful observing (hand near chin, kindly curious eyes), MIDDLE row proposing an idea (one index finger raised, friendly excited face), BOTTOM row celebrating learning (both arms up and happy smile). Exactly NINE independent waist-up portraits, one character per cell, centered at the same scale with identical head heights and generous padding on all sides. No full legs. Actual transparent background, clean alpha, no colored panels, no frames, no labels, no lettering, no symbols or extra people. No cropping of arms/head at cell boundaries. Output one square image with a strict regular 3x3 layout so CSS can address each equal cell. Preserve the reference and make the expressions distinct and natural, suitable for supportive play.»

Los gestos acompañan observar, pedir una idea y celebrar el esfuerzo. Los turnos se refieren a compartir un dispositivo; no crean perfiles ni mezclan datos de alumnos diferentes. La animación de celebración dura una sola vez y respeta movimiento reducido.
